GameStats

  1. Instalar Docker Desktop (unica herramienta necesaria) y abrirlo: docker.com/products/docker-desktop
  2. Descomprimir el proyecto y ejecutar el instalador:
    macOS y Linux: ./instalar.sh
    Windows: doble clic en instalar.bat
  3. Esperar unos minutos (la primera vez construye las imagenes). Se abre el panel solo, o pulsar:
Abrir el panel de GameStats
http://localhost:8081

Para detener: ./detener.sh o detener.bat.
